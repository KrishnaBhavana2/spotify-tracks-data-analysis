# Spotify Tracks Data Analysis

## Project Overview

This project focuses on analyzing a Spotify dataset containing 106,000+ tracks across 108 genres.

The main objective is to clean the data, perform Exploratory Data Analysis (EDA), create visualizations, and identify meaningful patterns related to track popularity.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Cleaning

- Inspected dataset structure and data types
- Checked missing values
- Removed unnecessary columns
- Cleaned text fields
- Handled missing values
- Removed 444 duplicate records

## Exploratory Data Analysis

- Analyzed popularity distribution
- Studied genre-wise popularity
- Analyzed relationships between audio features
- Compared audio features with popularity
- Compared explicit and non-explicit tracks

## Visualizations

Created:

- Histograms
- Boxplots
- Bar charts
- Hexbin plots
- Correlation heatmaps

## Key Insights

- Danceability, energy, and tempo showed weak direct correlation with popularity.
- Energy and loudness showed a strong positive relationship.
- Energy and acousticness showed a strong negative relationship.
- Pop-film, K-pop, and chill had higher average popularity in the analysis.
